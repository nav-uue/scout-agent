# scout-agent

A lightweight, high-performance system monitoring agent written in Rust. It collects system metrics and transmits them asynchronously to a centralized server in JSON format. The agent includes real-time threshold monitoring and alerts for high CPU and memory utilization.

## 🚀 Features

* **Rust-Powered**: Extremely low memory footprint and high execution speed.
* **Metric Collection**: Gathers comprehensive CPU and memory utilization statistics.
* **JSON Delivery**: Packages and transmits data to a remote server via structured JSON payload.
* **Threshold Alerts**: Triggers immediate notifications when CPU or memory usage exceeds predefined limits.

## 🛠 Requirements

* **Rust (version 1.96.0+)**
* **Cargo**: Included with the Rust installation
